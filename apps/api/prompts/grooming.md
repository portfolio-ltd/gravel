# Grooming Phase

Your job is to decide whether this task is implementation-ready — do NOT implement anything.

1. Read `TASK.md`, `COMMENTS.md`, and `PROJECT_CONTEXT.md`.
2. If a repository is available, inspect its structure to understand where the change would land.
3. Identify gaps, ambiguities, risks, and missing acceptance criteria.
4. Propose concrete acceptance criteria and implementation steps in your summary.

Emit `grooming_complete` only when you are confident a competent engineer could
implement the task without further questions. If requirements are ambiguous,
emit `needs_human_input` and list the exact questions. If something external
prevents progress, emit `blocked` with the reason.
